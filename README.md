# 家计账本 · 家庭收入、硬性支出与资产借贷管理

纯前端家庭月度账本应用，支持每月固定开支自动登记、收支汇总报表自动生成、分类标签管理、月底家庭货币资产与借贷盘点，以及按月/按年的数据可视化图表导出与 Excel（`.xlsx`）全量导入导出。

## 主要功能

- **收支概览**：按月 / 按年统计家庭总收入、硬性固定支出、可支配收入与可支配比例，展示待扣款提醒与月底资产借贷摘要。
- **固定开支模板**：集中维护房贷、物业水电、教育、保险、车贷等每月固定支出，支持一键登记至指定月份或补齐全年。
- **收支汇总报表**：自动按收入分类与硬性支出分类生成汇总报表，支持多标签筛选、Excel（`.xlsx`）/ CSV 导出及打印/PDF 保存。
- **家庭资产借贷**：每月底盘点储蓄卡余额、货币基金、积存金、股票账户，以及借贷账务与信用卡已用/授信额度，支持沿用上月账户结构与点击金额就地快改。
- **图表分析与导出**：纯月度粒度趋势图、分类占比环形图、成员贡献分布及资产借贷趋势图，均支持导出高清 PNG 与 SVG 矢量图。
- **Excel 导入导出**：内置标准 `.xlsx` 导入模板下载，支持合并追加与覆盖导入。

## 本地开发与构建

```bash
npm install
npm run dev      # 启动本地开发服务器 (http://localhost:3000)
npm run lint     # TypeScript 类型检查
npm run build    # 生产环境构建（输出至 dist/）
```

## GitHub Actions 流水线说明

- `.github/workflows/ci.yml`：每次推送到 `main` / `master` 或发起 PR 时自动执行依赖安装、TypeScript 类型校验、Vite 生产构建并上传 `dist` 产物。
- `.github/workflows/deploy-pages.yml`：用于一键构建并部署至 GitHub Pages（在仓库 `Settings → Pages` 中将 Source 设为 `GitHub Actions` 后，可在 Actions 页面手动触发或取消 `push` 触发注释实现自动部署）。
